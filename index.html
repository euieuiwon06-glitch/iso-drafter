    추가

    레이어 위 = 먼저 그림(뒤쪽)

      빈 곳 드래그 = 화면 이동 · 휠 = 확대/축소 · 요소 드래그 = 이동(5 단위 맞춤, Alt = 자유) · Delete = 삭제 · Ctrl+D = 복제

      요소를 선택하면 여기서 수치를 편집할 수 있어요.

      준비됨

      Anthropic API 키

      AI 초안·보정 기능에만 쓰여요. 키는 이 브라우저에만 저장되고, 요청은 Anthropic API로 바로 전송돼요. 사용 요금은 키 주인의 계정에 청구돼요(초안 1회에 대략 0.3~1달러).

      키는 console.anthropic.com → API Keys에서 만들 수 있어요. 공용 컴퓨터에서는 쓰고 나서 지워 주세요.
