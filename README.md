# ISO DRAFTER

이미지(손그림, AI 생성 이미지 등)를 깔끔한 **등각(아이소메트릭) 도면 SVG**로 다시 그리는 웹 에디터.

- **렌더 엔진**: 벽·바닥·유리벽·책상·의자·책장·계단·샤프트·동선·노드를 3D 박스로 다루고 정확한 30° 등각으로 그린다. 선 굵기·초록 팔레트 고정.
- **에디터**: 원본을 밑그림으로 깔고 요소를 추가·드래그·수치 편집. 되돌리기, JSON 저장/열기, SVG 내보내기.
- **AI 초안 / 보정**: 원본 위에 등각 좌표 격자를 그려 Claude(claude-opus-5-5)에게 보내 장면 데이터를 받는다. 보정은 현재 장면을 빨간 선으로 겹쳐 다시 맞춘다. API 키는 사용자 브라우저(localStorage)에만 저장된다.

```bash
npm install
npm run dev      # http://localhost:5341
npm run deploy   # dist → gh-pages
```
